Token counts only, not money: no prices or costs are applied. The report holds counts, agent ids, roles and issue numbers, never prompt or response text.

Transcript files read: 60. Agents: 60. Malformed lines skipped: 0.

## Scope and limits

- Covered: the 4 sessions in the container's Claude Code project directory for this repository (the v0.6.0 orchestrator session, 3 earlier sessions) and their subagent transcripts, 60 transcript files in all, as of 2026-10-20. The orchestrator session was still running, so its own counts are partial. This report's own implementation agent is included.
- Transcripts exist only in the session container; sessions run elsewhere are not covered.
- Attribution depends on issue numbers appearing in the agent prompt: the most frequent `#<number>` wins. A prompt that mentions another issue more often is misattributed, and main sessions (not subagents) are always unattributed with role other.
- Roles come from prompt keywords (CI fix, then review, then implement, else other) and are a heuristic.
- Token counts are summed from per-message usage in the transcripts, once per message id. Output counts may be lower than billed output if a transcript records usage before a streamed reply finished.
- Tokens only, not money.
