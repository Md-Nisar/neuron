# v0.7.0 release verification (#251)

Release gate record for v0.7.0 "Extensible Agent Platform" (ADR 0009). It states what is **met with
evidence** and what is **not done**. Everything ran locally with fake models, a local Postgres 16
and loopback servers. Staging and production were not exercised (out of scope until after v1.0.0).
This file does not tag or publish anything.

## Quality gates

| Command | Result |
| --- | --- |
| `make format lint typecheck test security` | ruff clean, mypy `no issues found in 70 source files`, **1588 passed, 2 skipped, 3 deselected**, bandit and `pip-audit` clean |
| Postgres integration (`APP_TEST_POSTGRES_DSN`, local Postgres 16) | all passed (about 131 tests; 11 live-OpenAI tests skipped, no key). Covers the store tables, grants, readiness and two-process cases. Local Postgres 16 without TLS |

## Known issues

- Anthropic was verified with fakes only; OpenAI was not run; production and staging were not exercised.
- No live model run of any v0.7.0 suite (criterion 2). Before tagging, replace the NVIDIA key and run `neuron-eval` with `--trials 3` for the regression and security suites, then `compare`.
- The security eval cannot see an injected call to a tool the caller may use (existing limit); the new `approval` suite covers the memory store directly.
- Memory is off by default, unavailable on the Agent Server path, and its item limit can be exceeded by concurrent writes.
