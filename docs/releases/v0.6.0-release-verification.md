criterion, what is **met with evidence** and what is **not done**. Nothing here was verified on
a real Render deployment: the owner deferred a real Render deploy for this milestone, so every
criterion that needs one is recorded as *not done*, not as passed. This file is a record of the
state at commit `77d7b61` plus the release preparation in this change; it does not tag or

## Findings during the milestone

- The nightly eval is broken independently of rate limits (criterion 12). Recorded on #157.
- Stacked PRs merged into their base branches, not `main`, so #156, #209 and #206 landed late
  (via #224): delete head branches on merge so GitHub retargets stacked PRs.
- CI Postgres had no TLS, so the start-up TLS check's success path was untested until #209;
  `verify-full` against a real certificate authority and a transaction pooler remain unproven.
- CodeQL flagged a checkout of `workflow_run.head_sha` in `deploy.yml`; fixed in #222.

## Decision needed before tagging

Tagging `v0.6.0` starts the production pipeline, which needs the Environments (criterion 3) and
a Render deployment. Criteria 5, 6, 8, 9, 11, 12 and 14 cannot be met without one. Release only
with the owner's recorded sign-off that these are accepted as *not done*, or after they are done.
