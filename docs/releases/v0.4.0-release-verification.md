# v0.4.0 Release Verification: Multi-User Security

Verification notes for the v0.4.0 authentication and Agent Server work. This is
an incremental record; the complete v0.4.0 release gate is tracked by issue #63.

## Agent Server Authentication Smoke (#58)

Run locally on 2026-10-10 with Python 3.14.3, `langgraph-api 0.15.4`,
`langgraph-cli 0.4.33`, and `langgraph-sdk 0.4.6`. The smoke used an ephemeral
RSA key and local JWKS HTTP endpoint; neither key material nor JWTs were stored
in the repository. No model call was made.

| Check | Result |
| --- | --- |
| `langgraph dev` loads `main` graph and custom auth from `langgraph.json` | Pass |
| Unauthenticated thread creation in JWT mode | `401` |
| User A creates a thread | `200`; metadata owner is an opaque HMAC identity, not the JWT subject |
| User B reads User A's thread | `404` |
| User B starts a run on User A's thread | `404` |
| Local development Studio identity (`APP_ENV=development`, `APP_AUTH_MODE=none`) | Pass; thread creation stamps `studio:development` |

The JWT smoke was executed against the local in-memory Agent Server. It verifies
the custom verifier, owner stamping, and cross-user thread/run isolation; it is
not a production LangSmith Deployment or multi-replica test.
