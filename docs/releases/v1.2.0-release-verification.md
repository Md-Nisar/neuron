# v1.2.0 release verification

Release record for v1.2.0 "Retrieval quality and sharing": RAG-E09 of
`docs/product/NEURON_RAG_PRODUCT_BACKLOG.md`, 8 stories (#545 to #552, epic #544). Hybrid search
can rerank its top results; knowledge bases can be shared by token role; an operator can re-index
to a new embedding model; a nightly gate holds retrieval quality; load scenarios record a baseline;
thumbs-down answers link to the chunks they cited; a base can be given its documents' language.
Knowledge stays off by default (`APP_KNOWLEDGE_ENABLED`). The `/v1` API and stream protocol
version 1 stay compatible: the grants routes and the `access`, `language` and `reranked` fields
are additions. Migrations 28 and 29 run only with knowledge on.

**No production environment exists**, as for v1.0.0 and v1.1.0. All evidence is local: the
reference stack (`docker-compose.reference.yml`), CI, and the NVIDIA free tier for the live checks.

**Sign-off:** pending the owner.

## Known issues

- No production environment, staging run or production-model run. The `production` job of
  `deploy.yml` cannot succeed, so the GitHub Release is published by hand from the `1.2.0`
  CHANGELOG section (`python3 scripts/changelog_section.py 1.2.0`).
- The live answer eval runs one trial per case, so a re-run can land near the 0.9 gate.
- Load figures describe one local host with fake embeddings and the plain-text parser; the
  reranker's latency was measured separately against NVIDIA's free tier.
- The reranker is hosted only: no self-hosted reranker (`tei`, `fastembed`) was built, so a
  `self_hosted_only` deployment cannot rerank.
- German word search finds a third of the evaluation's answers with the `german` configuration;
  `pg_textsearch` BM25 was not measured (PostgreSQL 17 or later; ADR 0014, "text search language").
- No story yet for a worker settings profile or for checking the worker role's column grants in
  production.
- The erase-flow browser test (`web/e2e/knowledge.spec.ts`) has a race on its second sign-in
  (tracker, recommended next action).
- Later phases (RAG-E10 to RAG-E12: external sources, specialised tools, platform and scale) have
  no issues yet.
