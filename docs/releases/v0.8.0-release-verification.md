## Known issues

- **Sign-in against a real Keycloak is untested.** The realm export and API settings are merged (#298), but the authorization-code flow, silent renew and `frame-ancestors 'self'` on the renew frame have never run in a browser. If the silent-renew test fails in a real browser, ADR 0010's fallback is `frame-ancestors 'none'` and no renew frame.
- **`nbf`.** The API requires `nbf` on access tokens. Whether real Keycloak tokens carry it is unchecked, and the requirement is unchanged. Relaxing it needs a real run, a test, a `SECURITY.md` update and `security-reviewer` sign-off.
- **CSP, headers and layouts** (360 px, dark mode, colour contrast) and **screen-reader behaviour** were checked only as policy text and in jsdom with axe.
- **Ratings** are not forwarded to LangSmith (#285). Answers on threads stored before 0.8.0 carry no run ID and cannot be rated.
- **Stack merge.** The 21 PRs were each tested on their parent, not on `main`; the combination briefly failed one test (the stream-contract fixture, fixed in #319).
- The micromark overrides in `web/package.json` can be dropped after 2026-12-25.

## Before tagging

1. Run Keycloak (the compose `keycloak` profile and `make dev-keycloak`, #298), the API and the web app together, and walk sign-in, chat, approve, resume, rename, delete, rate, export and erase in a real browser; add the Playwright suite.
2. Confirm whether real access tokens carry `nbf`.
3. Run the web app in a screen reader and check contrast and the 360 px layout.
4. Optionally record a live `--trials 3` run on the development model and a token usage report.
